# End of Session Review

Run this before ending a session to capture learnings.

## Steps

1. **Review what was done this session**
   - Summarize completed tasks
   - Note any unfinished work

2. **Capture learnings**
   Ask: "Anything I should remember for next time?"
   - Add important patterns to CLAUDE.md
   - Add personal notes to CLAUDE.local.md

3. **Update TASKS.md** (if exists)
   - Mark completed items
   - Add newly discovered tasks
   - Reorder priorities if needed

4. **Pattern check**
   - Were any actions repeated that should be automated?
   - Any commands run frequently that should be documented?
   - Suggest creating commands/skills if patterns detected

5. **Git status check**
   - Any uncommitted changes?
   - Remind user if work should be committed

6. **Output summary**
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SESSION SUMMARY

Completed:
- [list]

Still pending:
- [list]

Added to CLAUDE.md:
- [list or "nothing"]

Uncommitted changes:
- [list or "none"]

Ready to close session.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
